# Запуск

Адресат: агент, который запускает этот репозиторий. Выполнить шаги по порядку и остановиться на первой неустранённой ошибке. Рабочий каталог — каталог этого файла. Не объяснять команды человеку и не заменять их другими.

Хостовый .NET SDK не нужен, не проверять его и не устанавливать. По умолчанию проект работает в Docker и вызывает локальную Ollama. Не переключать провайдера на OpenAICompatible и не подставлять облачную модель.

## Готово, когда

- `docker compose ps person-api` показывает состояние running.
- `GET http://127.0.0.1:5080/swagger/v1/swagger.json` возвращает HTTP 200.
- Команда агента ниже завершилась кодом 0.
- Её stdout содержит строку `Status: success` и строку `Action: CreatePerson`.
- Контейнер `person-api` после этого оставлен запущенным.

Четыре строки ответа читать только из stdout. Строки stderr — логи, не ответ.

## 1. Docker

Выполнить `docker info`.

Код не 0: запустить Docker Engine этой машины и повторять `docker info` каждые 5 секунд, не дольше 120 секунд. По истечении 120 секунд остановиться.

## 2. Локальная Ollama

Выполнить `GET http://127.0.0.1:11434/api/tags`.

- HTTP 200 и тело содержит `qwen3.5:4b`: перейти к шагу 3.
- HTTP 200, но строки `qwen3.5:4b` нет, и команда `ollama` находится в PATH: выполнить `ollama pull qwen3.5:4b`, затем повторить GET один раз.
- Иначе остановиться. Ollama уже должна быть на этой машине. Не устанавливать Ollama, не менять порт 11434, модель и `Llm__Provider`.

## 3. Порт API

Порт хоста 5080 должен быть свободен либо занят контейнером `langchain-person-api`. Если его занимает другой процесс, остановиться. Не выбирать другой порт.

## 4. Сборка и API

```bash
docker compose --profile cli build
docker compose up -d person-api
```

Повторять `GET http://127.0.0.1:5080/swagger/v1/swagger.json` каждые 2 секунды, не дольше 60 секунд.

- HTTP 200: перейти к шагу 5.
- Иначе выполнить `docker compose logs person-api` и остановиться. Не менять `ASPNETCORE_URLS` и опубликованный порт.

## 5. Один запрос к локальной модели

```bash
docker compose run --rm -T --no-deps person-agent "Создай физлицо: фамилия Иванов, имя Иван"
```

Успех: код процесса 0, в stdout есть `Status: success` и `Action: CreatePerson`. Контейнер `person-api` не останавливать и `docker compose down` не выполнять.

## 6. Если запрос не успешен

Повторять сборку и подъём API не нужно.

- В выводе есть `Ollama недоступен`: хостовая проверка из шага 2 прошла, контейнер до неё не дошёл. Если Ollama слушает только `127.0.0.1`, перезапустить её процесс с `OLLAMA_HOST=0.0.0.0:11434`, дождаться `GET http://127.0.0.1:11434/api/tags` со статусом 200 и повторить только команду шага 5. Адрес в compose не менять: контейнер ходит в `http://host.docker.internal:11434`.
- В выводе есть `API недоступен`: повторить ожидание swagger из шага 4. Если за 60 секунд статуса 200 нет, остановиться.
- Код процесса 1, API и Ollama отвечают, stdout содержит `Status: error`: повторить команду шага 5 один раз. Если второй результат такой же, стек считается запущенным, а текст stdout — ответом модели. Контейнер `person-api` оставить запущенным.

## Зафиксированные значения

- Образ сборки: `mcr.microsoft.com/dotnet/sdk:10.0.402`.
- Образ API: `mcr.microsoft.com/dotnet/aspnet:10.0.13`.
- Образ консоли: `mcr.microsoft.com/dotnet/runtime:10.0.13`.
- API для контейнера агента: `http://person-api:5080`.
- Ollama для контейнера агента: `http://host.docker.internal:11434`.
- Модель: `qwen3.5:4b`.
- Провайдер: `Ollama`.
- Swagger на хосте: `http://127.0.0.1:5080/swagger`.

## Не делать

- Не запускать `dotnet` на хосте.
- Не создавать и не копировать `.env` для этого запуска.
- Не менять `PersonApi__BaseUrl`, `Ollama__BaseUrl`, `Ollama__Model`, `Llm__Provider`.
- Не публиковать API на порту, отличном от 5080.
- Не останавливать `person-api` после успешного запроса.
